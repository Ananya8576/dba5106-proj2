Which team gets this wafer?

A wafer shows a local cluster of failing dies. The model predicts which of two look-alike patterns it is.

Edge-Loc: hold the tool

A tool’s edge process is drifting. It repeats on every wafer.

Loc: normal review

A one-off particle or local event on that wafer.

Data

WM-811K, real fab wafer maps. 8,782 labelled wafers, 59% Edge-Loc. We built 10 physical features per map.

Evaluation loss

(5 × missed Edge-Loc + 1 × false alarm) / wafers. A missed tool problem costs 5 unnecessary holds. Our assumption.

Why this question

“Defect or no defect” is almost perfectly predictable here (AUC 0.995). We chose a harder, more useful question.

Orange = failing die, light blue = passing die. Source: WM-811K (Kaggle, qingyi/wm811k-wafer-map).

The decision: a wafer shows a local cluster of failing dies. Edge-Loc means a tool's edge process is drifting, so we hold the tool. Loc is a one-off particle. The two mistakes don't cost the same: a missed Edge-Loc lets the tool keep damaging lots, a false alarm costs one unnecessary tool hold. We assume 5 to 1; that ratio is our assumption and we test other ratios later. Data: WM-811K, 8,782 wafers labelled Edge-Loc or Loc by engineers. We turned each wafer map into 10 physical features, such as fail rate by zone and where the largest cluster sits. We did not use the easier question, defect versus no defect, because it is almost perfectly predictable (AUC 0.995).
