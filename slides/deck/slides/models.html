+0.008 for the glassbox, +0.007 for the blackbox. Both intervals exclude zero. L2 scores fall outside 0–1 for 20–29% of wafers.

Why validation, not training

The blackbox scores 1.000 on its own training data and 0.972 on validation.

How we kept it fair: split by lot, 60 / 20 / 20. Each model tuned separately by cross-validation inside the training split. 24 configurations in total.

Solid = log loss, dashed = L2. Intervals resample whole lots, 2,000 times. Validation: 1,756 wafers.

Glassbox: an L1-penalised linear model. With L2 loss that is LASSO regression on the 0/1 label; with log loss it is L1 logistic regression. Blackbox: gradient-boosted trees, with squared error and with log loss. Within each row only the training loss changes. Each of the four was tuned separately by 5-fold cross-validation inside the training split, with folds by lot: 6 penalty values for the glassbox, tree depth times number of trees for the blackbox, 24 configurations in total. The validation split was used only to compare the four tuned models. Log loss wins for both model types. We split by lot because wafers from one lot look alike, and a random split would flatter validation.
