Which to trust

Run 1. Run 2 has the bigger gap, but its model reads how the dataset was built, and its 49% scratch rate is artificial.

AUC and loss rows are validation, log-loss models, at each model’s best threshold. Test splits used once: 1,758 wafers (run 1), 7,398 (run 2). Loss levels are not comparable across runs.

Test result for the second run, used once: AUC 0.882, evaluation loss 0.330 per wafer, 36 percent below holding the tool for every wafer. Validation and test agree, 0.328 against 0.330, because the validation split is four times larger than in the first run, so there is little optimiser's curse. The audit agrees with the choice: the glassbox we did not choose scores 0.513 on test. Now the comparison. Same pipeline, same grids, same cost ratio, same decision rule. The rule picks the glassbox in run 1 and the blackbox in run 2, for a reason we can explain: a linear model captures edge versus interior, but not a thin line among other defects. Log loss beats or ties L2 in every case. Tuning the threshold pays off in both, more where the model is weaker. Better calibration puts the searched threshold closer to the theoretical one. Which result do we trust? Run 1: real data, and a model whose explanation matches the physics. Run 2 has the more dramatic gap, but SHAP shows its model reads how the dataset was assembled, and its 49 percent scratch rate is artificial, so its loss levels cannot be compared with run 1 or with a real fab. Limits for both: the 5 to 1 cost ratio is our assumption.
