Audit of our own choice

On test, the glassbox we didn’t choose scores 0.426 against our 0.263. The difference (+0.162, 95% CI +0.134 to +0.191) confirms the choice. Validation and test agree: 0.250 vs 0.263.

Limits

The 49% scratch rate is artificial, so the cost is not a fab forecast. The 10:1 ratio is our assumption. Half of the model’s attribution is background. The dataset has no lots, so the split is random.

What we did differently

Built line features for the question. Left out position and the die count on purpose. 32 configurations, test used once, an interval on every comparison.

Final model: boosted trees (log loss) + Platt scaling, threshold 0.105. Test split: 7,398 wafers. An earlier version with other features was scored on this split once.

The test split, with the model, calibrator and threshold frozen. AUC 0.961. Evaluation loss 0.263 per wafer, which is 49 percent below flagging every wafer and 59 percent below using a 0.5 threshold. We catch 98.4 percent of scratched wafers, with a precision of 72 percent. Validation and test agree, 0.250 against 0.263, helped by a validation split of 7,398 wafers. Audit: after freezing everything we scored the glassbox we did not choose. It costs 0.426 on test, clearly worse, so the choice holds. Limits. The 49 percent scratch rate is artificial, because the dataset's authors balanced the classes, partly with generated maps; the cost per wafer is not a forecast for a real fab. The 10 to 1 cost ratio is our assumption. Half of the model's attribution comes from background features. The dataset has no lot information, so the split is random. And one disclosure: an earlier version of this analysis, with a different feature set, was scored on this same test split once; the features and grids we present were designed on the training split.
