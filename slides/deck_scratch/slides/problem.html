This is the second run. We repeat the whole pipeline of the first project on a different semiconductor dataset, to see whether the same method reaches the same decision. The question: does this wafer have a scratch? A scratch is a thin line of failing dies from mechanical contact. In this dataset one wafer can carry several patterns at once, so the scratch has to be found among other defects; even by eye it is hard to see in these two examples. Data: MixedWM38, 36,991 wafer maps after cleaning. Two cleaning steps were needed before the task was honest: we dropped 1,024 exact duplicate maps, 97.7 percent of which were scratch wafers, and we deleted the die-count feature, because in this dataset it gives the label away. The 49 percent scratch rate is artificial: the authors balanced the classes, partly with generated maps. Everything else is identical to the first run: the features, the four models, the search grids, the 60/20/20 split, and the 5 to 1 evaluation loss.
