A scratch is a line, so we built features for a line. Seven of the sixteen features measure line-shaped evidence: how much of the failing area is thin, how long the longest thin structure is, and how strongly failing dies line up in one direction. The other nine describe the background: how many dies fail, where, and how clustered. We designed the line features on the training split only, in three rounds, and fixed them before tuning any model. On their own, the seven line features are the seven strongest single features. No feature says where on the wafer the line is: in these maps scratches tend to sit in the same region, and a real scratch can be anywhere. Models: an L1-penalised linear model as the glassbox, gradient-boosted trees as the blackbox, each trained with L2 loss and with log loss. Each was tuned separately by cross-validation inside the training split: 7 penalty values for the glassbox, depth times number of trees for the blackbox, 32 configurations. Log loss wins for both. Training AUC of the blackbox is 0.989 against 0.963 on validation, which is why we compare on validation.
