Calibration: already good, and the threshold shows it

0.013 → 0.009

calibration error (ECE) of the chosen model; AUC unchanged

What we found

Boosted trees trained with log loss on 22,195 wafers were close to calibrated from the start.

The fix

Platt scaling, fitted on out-of-fold training scores. A small gain. In the first run isotonic regression was the better fix.

Why it matters

Theory gives the threshold for calibrated probabilities: 1/(1+5) = 0.167. Ours is 0.155. In the first run, with worse calibration, it was 0.22.

Validation split, equal-count bins. For cost ratios 1 to 4 the searched threshold is within 0.02 of the formula.

Same calibration check as in the first run: reliability diagram, expected calibration error and Brier score for all four models. Here the chosen model was already close to calibrated: an error of 0.013 before any fix. Platt scaling, fitted on out-of-fold training scores, takes it to 0.009 without changing AUC. In the first run the chosen model was a logistic regression with an error of 0.031, and isotonic regression was the better fix. The link to the threshold is clearer here. With calibrated probabilities, decision theory gives the threshold as 1 over 1 plus the cost ratio, 0.167. Our searched threshold on calibrated probabilities is 0.155. In the first run it was 0.22. So the better calibrated the model, the closer the searched threshold is to the formula. For cost ratios from 1 to 4, the searched threshold matches the formula to within 0.02.
